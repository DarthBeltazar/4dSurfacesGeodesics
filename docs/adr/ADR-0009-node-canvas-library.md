# ADR-0009: Библиотека холста нод — imgui-node-editor, ImGui на ветке docking

**Контекст.** DD-011 §8 оставлял выбор холста редактора нод короткой пробе: imnodes (Nelarius) или imgui-node-editor
(thedmd), обе MIT и поверх Dear ImGui. Требования: масштаб и прокрутка холста, связи, выделение (в том числе рамкой),
совместимость с веткой docking ImGui (панель нод пристёгивается к стороне окна, картинка — в оставшейся области).

**Проба** (каталог сборки вне репозитория, исходник — в журнале 2026-10-25-02): обе библиотеки собраны с ImGui
`v1.91.9b-docking` (MSVC 2022, `/utf-8`) и нарисовали три кадра графа «Горловина → Сцена» без GPU: ноды, порты,
связь, `DockSpaceOverViewport`. Ошибок и предупреждений сборки нет.
- imnodes (последний коммит `2d0c280`): **нет масштаба холста** — в API нет ни уровня, ни колеса мыши; есть
  мини-карта.
- imgui-node-editor `v0.9.4`: масштаб колесом мыши (плавный — `EnableSmoothZoom`, свои уровни), навигация к выделению,
  выделение рамкой, очереди создания и удаления связей и нод (`BeginCreate`/`BeginDelete`), контекстные меню холста,
  ноды и связи. Положения нод читаются и задаются (`GetNodePosition`/`SetNodePosition`).

**Решение.**
- Холст — **imgui-node-editor v0.9.4**: без масштаба граф из десятков нод (листы с горловинами и составные объекты)
  на экране не умещается. Файл настроек библиотеки отключён (`SettingsFile = nullptr`): положения нод хранятся в
  `.g4d` (`ui.pos`, DD-011 §1) — сцена переносится с ними, а undo/redo — снимки одного документа.
- ImGui — тег **`v1.91.9b-docking`** (та же версия, что была, с веткой docking): пристёгивание панелей к сторонам
  окна, картинка — в центральном узле докспейса. Обе зависимости — FetchContent с закреплённым тегом.

**Последствия.**
- Код imgui-node-editor собирается в `geo4d_imgui` (4 файла); библиотека использует внутренние API ImGui — при
  обновлении ImGui сначала проверить её сборку.
- Ветка docking меняет поведение окон ImGui только при включённом `ImGuiConfigFlags_DockingEnable`; плавающие окна
  редактора работают как раньше.
- imnodes не используется.
