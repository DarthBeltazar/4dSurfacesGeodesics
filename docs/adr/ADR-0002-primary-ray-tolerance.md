# ADR-0002: Допуск первичного луча tol = κ·θ_pix

**Контекст.** Задание требует привязать допуск первичного луча к угловому размеру пикселя θ_pix.
Норма M8 оценивает локальную ошибку шага, а не глобальную ошибку выходного направления, так что κ нужно
подобрать по измерению.

**Измерение.** `results/stage-1/2026-10-23_render_benchmark/sweep.csv`: первичные лучи 96², fov 90°
(θ_pix = 0.0208), BS32 stale, эталон DOPRI5 при tol = 1e-12. Ошибка выходного направления в θ_pix:

| κ = tol/θ_pix | Эллис p99 / max | компактная p99 / max | SDF/пиксель (Эллис / компактная) |
|---|---|---|---|
| 2.6e-2 | 0.075 / 0.54 | 0.024 / 4.9 | 42 / 68 |
| 5.9e-3 | 0.024 / 0.091 | 0.0093 / 1.3 | 62 / 89 |
| 1.4e-3 | 0.0081 / 0.053 | 0.0028 / 0.30 | 88 / 129 |
| 3.2e-4 | 0.0024 / 0.017 | 0.00094 / 0.084 | 126 / 187 |

Выбросы по максимуму у компактной червоточины — касательные лучи у края шара ρ₀ (доли процента пикселей).

**Решение.** κ = 1e-3 по умолчанию (`render_ellis.py --kappa`): p99 ≤ 0.01 θ_pix на обеих сценах,
максимум ≤ 0.1 θ_pix у Эллиса. Строгий максимум ≤ 0.1 θ_pix на компактной требует κ ≈ 3e-4.
Для превью годится κ = 1e-2 (p99 ≤ 0.03 θ_pix).

**Последствия.** Рендер Эллиса 512² при κ = 1e-3: в среднем 144 прохода SDF на пиксель
(`results/stage-1/2026-10-23_ellis_render/stats.json`). Перенос κ на другие разрешения предполагает,
что ошибка ∝ tol; это не проверено отдельно. На этапе 2 проверить вместе с лучевыми конусами и AA.

**Статус.** Accepted, 2026-10-23.
