# ADR-0005: Фильтрация фона на GPU: SampleGrad с k = 2, BC6H, программный фильтр M19 опцией

**Контекст.** DD-004 п. 8: аппаратная анизотропная выборка `SampleGrad(d, k σ₊ a₊, k σ₋ a₋)`, коэффициент k
калибруется; ошибка BC6H измеряется отдельно от ошибки фильтра (контроль RGBA16F).

**Измерение.** `results/stage-3/2026-10-24_gpu_modea_quality/table.md`: Эллис 128², против эталона 1024 spp
этапа 2 (шумовой пол 55.8 / 51.0 дБ), PSNR без фолбэка:

| | pinhole | DoF |
|---|---|---|
| SampleGrad, RGBA16F, k = 1 / 1.5 / **2** / 2.5 / 3 | 34.5 / 38.4 / **39.0** / 37.8 / 34.3 | 34.1 / 36.0 / **36.9** / 36.0 / 35.3 |
| SampleGrad, BC6H, k = 2 | 38.8 | 36.4 |
| программный M19 (до 16 трилинейных SampleLevel), RGBA16F | 40.3 | 37.2 |
| программный M19, BC6H | 40.1 | 36.7 |
| прототип: M19 с боксовыми мипами / точный гауссов фильтр | 41.7 / 46.9 | 40.2 / 45.8 |

С фолбэком (детектор по умолчанию, 256 spp) SampleGrad и M19 сравниваются: 41.2 / 41.3 дБ (pinhole), 38.0 / 37.6 дБ (DoF).
Стоимость оттенения 1080p: SampleGrad 0.29 мс, M19 0.33 мс (`shade_1080p_ms.json`).

**Решение.** По умолчанию — аппаратный `SampleGrad` с k = 2 и BC6H (GPURealTimeBC6H, качество с P2-модами).
Программный фильтр M19 — опция (`filter_mode = 1`): +0.3…+1.3 дБ без фолбэка при +0.04 мс.

**Последствия.** Главная оставшаяся ошибка режима A — фильтр текстуры (−7…−9 дБ против точного гауссова фильтра).
Кандидаты на улучшение: гауссово префильтрованные мипы, больше отсчётов M19, выше разрешение кубмапы.

**Статус.** Accepted, 2026-10-24.
