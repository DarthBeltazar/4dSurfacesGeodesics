# ADR-0001: Параметр стабилизации Баумгарта α

**Контекст.** M2 содержит α; задание предлагает α порядка 1/масштаб геометрии. Проекция M3 после каждого
принятого шага уже возвращает x на M и v в касательную плоскость, так что Баумгарт действует только
внутри шага (на стадиях RK, где x и v слегка сходят с M).

**Измерение.** `results/stage-1/2026-10-23_alpha_sweep/` (таблица `table.md`): BS32, 32 луча,
α ∈ {0, 0.1, 1, 10}/ℓ_s, tol ∈ {1e-4, 1e-6, 1e-8}, фигуры S³, эллипсоид, «тигр», Эллис, компактная червоточина.
- α = 0 и α = 0.1/ℓ_s неразличимы по стоимости и дают наименьшую ошибку.
- α = 1/ℓ_s: ошибка у Эллиса и компактной червоточины в 2–7 раз больше, стоимость та же.
- α = 10/ℓ_s: ошибка больше в 10–100 раз, число отказов шага растёт; на компактной червоточине при
  tol = 1e-4 — NaN (нестабильность).

**Решение.** α = 0.1/ℓ_s (`Shape.alpha`). Нулевое α не берём: на GPU во float32 проекция неточнее, и малое
затухание дрейфа ограничения внутри шага может понадобиться; проверить на этапе 3.

**Последствия.** Отклонение от формулировки задания («порядка 1/масштаб») — на порядок меньше, обосновано
измерением. Пересмотреть при переходе на float32 (этап 3).

**Статус.** Accepted, 2026-10-23.
