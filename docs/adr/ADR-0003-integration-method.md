# ADR-0003: Метод интегрирования — BS32 основной, DOPRI5 опцией

**Контекст.** Бенчмарки этапа 1 (`results/stage-1/2026-10-23_benchmark`, `…_render_benchmark`,
`…_render_benchmark_ellis_nocap`) показали:
- первичные лучи Эллиса без ограничения шага: при p99 ≤ 0.1 θ_pix BS32 stale 41 проход SDF на пиксель,
  DOPRI5 60; при ≤ 0.01 θ_pix 82 против 73;
- длинные пути по компактным фигурам с точностью ≤ 1e-5: DOPRI5 дешевле в 2–10 раз.

**Решение** (согласовано с пользователем 2026-10-23). BS32 с FSAL «stale» — рабочий метод по умолчанию
(`Config.method = "bs32"`). DOPRI5 остаётся опцией (`Config.method = "dopri5"`) — для эталонов, лучей
с жёсткими требованиями к точности и длинных путей. Поддерживать оба метода и в GPU-порте (этап 3).

**Последствия.** Поля Якоби (этап 2) интегрируются тем же общим вложенным RK, так что работают с обоими методами.
На этапе 3 бюджет регистров считать для BS32 (4 стадии), DOPRI5 — отдельным вариантом ядра.

**Статус.** Accepted, 2026-10-23.
