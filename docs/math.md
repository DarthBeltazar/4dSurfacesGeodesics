# Формулы и конвенции

Единый источник формул проекта. В коде ссылаться на номера: `# M2: геодезическая, см. docs/math.md`.
Если формула оказалась неверной — исправить здесь, отметить в журнале сессии и в CHANGELOG.

## Конвенции

- Объемлющее пространство R⁴, точка p = (x, y, z, w), индексы 0..3.
- Многообразие M = {p : f(p) = 0}, f гладкая, ∇f ≠ 0 на M. |∇f| = 1 **не** предполагается.
- Нормаль n = ∇f / |∇f| (направлена в сторону роста f).
- Лучи параметризуются длиной дуги s, |v| = |ẋ| = 1.
- ρ = |(x, y, z)| — «сферический» радиус в первых трёх координатах.
- Lᵢⱼ = xᵢvⱼ − xⱼvᵢ — момент в плоскости (i, j).
- **Камера (этап 1).** Pinhole в касательном пространстве точки камеры: базис (forward, right, up) из
  касательных векторов. Эллис на ℓ_c: forward = −e_ℓ (на горловину), right = ŷ, up = ẑ (M9).
  Компактная червоточина: камера в плоской зоне (ρ_c ≥ ρ₀, w = W), forward = −x̂, right = ŷ, up = ẑ.
  Пиксель (i, j) ↦ u = ((i + ½)/W·2 − 1)·tan(fov/2), v = (1 − (j + ½)/H·2)·tan(fov/2)·H/W,
  d = normalize(forward + u·right + v·up). θ_pix = 2 tan(fov/2)/W — угловой размер центрального пикселя.
  Код: `render.pinhole_dirs`.
- **Пролёт в плоской зоне.** Луч из камеры в плоской зоне идёт по прямой до сферы |q − c| = ρ₀ аналитически
  (`wormholes.flat_flight_to_sphere`); лучи, не пересекающие сферу, не интегрируются (0 вызовов SDF).
- **Лист** выхода — sign(w) в точке выхода; направление на бесконечности — в координатах (x, y, z) листа.

## M1. Ограничение и его производные

Вдоль кривой x(s): C = f(x), Ċ = ∇f·v, C̈ = vᵀHv + ∇f·ẍ, где H — гессиан f.

## M2. Уравнение геодезической (внешняя форма, стабилизация Баумгарта)

    ẋ = v
    v̇ = −(vᵀHv + 2α ∇f·v + α² f) · ∇f / |∇f|²

Вывод: у геодезической ускорение нормально, ẍ = λ∇f. Требуем C̈ + 2αĊ + α²C = 0
(критически задемпфированный осциллятор для дрейфа ограничения), подставляем M1 и находим λ.
На точном решении f = 0, ∇f·v = 0, и M2 сводится к ẍ = −(vᵀHv)∇f/|∇f|².
Проверка: U2, U3, U5.

## M3. Проекция после принятого шага

    x ← x − f ∇f / |∇f|²          (один шаг Ньютона вдоль ∇f)
    n = ∇f / |∇f|
    v ← normalize(v − (v·n) n)

f и ∇f берутся из jet-вычисления в непроецированной точке (см. DD-001: FSAL).
После шага Ньютона остаток f = O(f²). Проверка: U3.

## M4. Jet-числа первого типа (7 компонент)

J = a + b·t + c·t² + Σᵢ dᵢ sᵢ,  t³ = 0, t·sᵢ = 0, sᵢsⱼ = 0.
Смысл: J = F(x + t v + s) с точностью до указанных порядков.

- Засев координаты k: (x_k, v_k, 0, e_k).
- Результат прохода SDF: f = a, ∇f·v = b, vᵀHv = 2c, ∇f = d.
- Сумма — покомпонентно, константа — (a, 0, 0, 0).
- Произведение: (a₁a₂, a₁b₂ + b₁a₂, a₁c₂ + b₁b₂ + c₁a₂, a₁d₂ + d₁a₂).
- Унарная g: (g(a), g′(a)·b, g′(a)·c + ½g″(a)·b², g′(a)·d).

Используемые унарные функции (g, g′, g″):

| g | g′ | g″ |
|---|---|---|
| 1/u | −1/u² | 2/u³ |
| √u | 1/(2√u) | −1/(4u^{3/2}) |
| eᵘ | eᵘ | eᵘ |
| cosh u | sinh u | cosh u |
| sinh u | cosh u | sinh u |
| ln u | 1/u | −1/u² |
| uⁿ (целое n) | n uⁿ⁻¹ | n(n−1) uⁿ⁻² |

Проверка: U1.

## M5. Jet-числа второго порядка по 4 переменным (полный гессиан)

J = a + gᵀε + ½ εᵀHε,  ε ∈ R⁴, члены порядка ε³ отбрасываются.
Хранится a, g ∈ R⁴, H ∈ R⁴ˣ⁴ (симметричная, 1 + 4 + 10 = 15 независимых компонент).

- Засев координаты k: (x_k, e_k, 0).
- Произведение: (a₁a₂, a₁g₂ + a₂g₁, a₁H₂ + a₂H₁ + g₁g₂ᵀ + g₂g₁ᵀ).
- Унарная φ: (φ(a), φ′(a) g, φ′(a) H + φ″(a) g gᵀ).

Нужно для оператора формы (этап 2). Проверка: U1 (полный гессиан против `jax.hessian`).

## M6. Гладкие примитивы

- **Гладкий минимум** (C∞, log-sum-exp):
  smin_k(a, b) = −k ln(e^{−a/k} + e^{−b/k}).
  Вычисляется в устойчивой форме min(a,b) − k ln(1 + e^{−|a−b|/k}); выбор ветви — по значению,
  каждая ветвь — точная запись одной и той же гладкой функции, поэтому jet-производные корректны.
  Полиномиальный smin Киглеза запрещён: у него разрывна вторая производная, а в правую часть M2
  входит гессиан.
- **Защищённая длина**: length(u) = √(max(|u|², ε²)), ε = 1e-150 в float64.
  Точна везде, кроме |u| < ε; поверхности отделены от осей, так что ветвь-заглушка на M не встречается.
  (Вариант √(|u|² + ε²) отвергнут: он сдвигает нулевое множество.)

## M7. Bogacki–Shampine 3(2) с FSAL

    k1 = F(y)
    k2 = F(y + h·½ k1)
    k3 = F(y + h·¾ k2)
    y⁺ = y + h(2/9 k1 + 1/3 k2 + 4/9 k3)          (3-й порядок, принимается)
    k4 = F(y⁺)                                    (FSAL: k1 следующего шага)
    ŷ⁺ = y + h(7/24 k1 + 1/4 k2 + 1/3 k3 + 1/8 k4) (2-й порядок)
    e  = y⁺ − ŷ⁺

Контроль шага: h_new = h · clamp(0.9 (tol/err)^{1/3}, 0.2, 5); шаг принят, если err ≤ tol.
Для DOPRI5 (сравнение) — та же схема с показателем 1/5.
Дополнительно h ≤ `Shape.hcap(x)` (DD-001). Проверка: U2, график сходимости (`scripts/convergence.py`).

## M8. Норма ошибки по касательным компонентам

e = (e_x, e_v), n — нормаль в y⁺ (из k4):

    e_x,t = e_x − (e_x·n) n,  e_v,t = e_v − (e_v·n) n
    err = max(|e_x,t| / ℓ_s, |e_v,t|)

ℓ_s — масштаб геометрии сцены (единица длины, в которой ошибка позиции эквивалентна угловой).
Нормальные компоненты не учитываются: их исправляет M3. Проверка: U2–U4, `test_wormholes.py`.

## M9. Червоточина Эллиса

    f = ρ − b cosh(w/b)

Нулевое множество: ρ = b cosh(w/b). Меридиан (ρ(w), w): dℓ² = dρ² + dw² = cosh²(w/b) dw², откуда

    ℓ = b sinh(w/b),   r = ρ = b cosh(w/b),   r² = ℓ² + b²,
    ds² = dℓ² + (ℓ² + b²) dΩ².

Касательный базис в точке (ρ, 0, 0, w) на меридиане: e_ℓ = (ℓ/r · ρ̂, b/r) — единичный, в сторону роста ℓ.

**Угол отклонения (эталонная квадратура).** Луч в экваториальной плоскости с моментом L = r sin β
(β — угол между v и радиальным направлением):

    dφ/dℓ = L / (r² √(1 − L²/r²)) = L / (r √(r² − L²))

- L < b: поворотной точки нет, φ = ∫ по всему пути.
- L > b: поворот при r = L, ℓ_t = √(L² − b²). Замена ℓ = ℓ_t + σ² убирает особенность:
  dφ = 2L dσ / (r √(2ℓ_t + σ²)).
- L ≈ b — неустойчивая орбита на горловине; такие параметры исключаются или помечаются.

Проверка: `test_ellis_deflection_50`.

## M10. Поправка на хвост Эллиса при выходе луча

Кривизна Эллиса не обращается в ноль, поэтому интегрирование обрывается при |ℓ| = ℓ_max,
а остаток угла добавляется аналитически (подстановка u = 1/ℓ):

    Δφ(ℓ) = ∫_ℓ^∞ L dℓ′ / (√(ℓ′² + b²) √(ℓ′² + b² − L²))
          = ∫_0^{1/ℓ} L du / (√(1 + b²u²) √(1 + (b² − L²)u²))

Подынтегральное выражение гладкое на малом отрезке, считается квадратурой Гаусса–Лежандра (8 узлов).
Асимптотическое направление: единичный вектор в плоскости движения (в R³ листа),
повёрнутый от текущего радиального направления r̂ на φ_∞ − φ = Δφ в сторону движения.
Проверка: `test_ellis_tail_correction`, `test_ellis_deflection_50`.

## M11. Червоточина с компактной кривизной

    f = w² − h(ρ),  h(ρ) = W² ψ(u),  u = (ρ − b)/(ρ₀ − b)
    ψ(u) = 1 − exp(1 − 1/(1 − u))   при u < 1,
    ψ(u) = 1                        при u ≥ 1.

Свойства:
- ψ ∈ C∞ (функция типа exp(−1/x) у u = 1), ψ(0) = 0, ψ′(0) = 1, ψ′ > 0 на (−∞, 1), ψ < 0 при u < 0.
- Нулевое множество: w = ±√h(ρ) при ρ ≥ b; при ρ < b f = w² − h > 0, лишних компонент нет.
- На горловине ρ = b, w = 0: ∇f = (−h′(b) ρ̂, 0), h′(b) = W²/(ρ₀ − b) ≠ 0 — поверхность гладкая,
  около горловины ρ − b ≈ w²/h′(b).
- При ρ ≥ ρ₀ = R_out оба листа — гиперплоскости w = ±W, кривизна ровно ноль; луч летит по прямой.
- Внутренняя метрика: r = ρ, dℓ = √(1 + (dw/dρ)²) dρ, r(ℓ) чётная, гладкая, r(0) = b,
  r′(ℓ) = sign(ℓ) при |ℓ| ≥ ℓ₀ (ℓ₀ — длина меридиана от горловины до ρ₀).
- Эталонный угол отклонения — M9 с r(ℓ) в параметризации по ρ:
  dφ = L √(1 + w′(ρ)²) dρ / (ρ √(ρ² − L²)).

Обоснование выбора — DD-002. Проверка: `test_compact_profile`, `test_compact_deflection`, U1–U6.

## M12. Две компактные червоточины

При непересекающихся шарах |q − cᵢ| < ρ₀ (центры cᵢ ∈ R³):

    f = w² − (h(ρ₁) + h(ρ₂) − W²),  ρᵢ = |(x,y,z) − cᵢ|

Около каждой горловины второе слагаемое тождественно W², так что f совпадает с M11. Без min/max.
Проверка: U1 (`two_compact_wh`); интегрирование — этап 4.

## M13. Точные решения и инварианты для тестов

- Гиперплоскость f = w: x(s) = x₀ + s v₀.
- S³, f = |p| − R: x(s) = cos(s/R) x₀ + R sin(s/R) v₀; период 2πR, сопряжённые точки на πR.
- S²×R, f = |(x,y,z)| − R: q = (x,y,z), u = v_q(0), c = |u|, ω = c/R:
  q(s) = cos(ωs) q₀ + sin(ωs)/ω · u;  w(s) = w₀ + v_w s.
- S¹×R², f = |(x,y)| − R: θ(s) = θ₀ + (v_θ/R)s, (z, w) — линейно.
- Эллипсоид f = |p ⊘ a| − 1: интеграл Иоахимсталя (Σ xᵢ²/aᵢ⁴)(Σ vᵢ²/aᵢ²) = const.
- Если f инвариантна относительно вращений в плоскости (i, j), Lᵢⱼ сохраняется точно
  (инвариантность ⇔ xᵢ∂ⱼf − xⱼ∂ᵢf = 0; ускорение ∥ ∇f ⇒ dLᵢⱼ/ds = xᵢv̇ⱼ − xⱼv̇ᵢ = 0;
  это верно и для M2 вне M, так что сохранение точное с точностью до интегратора).
- U5: f ↦ φ(f) при φ(0) = 0, φ′ > 0 (f + f³, f eᶠ) и f ↦ f·(1 + ½|p|²) не меняют геодезических.
- U6: f′(p) = f(Qᵀ(p − t)), Q ∈ SO(4) ⇒ x′(s) = Q x(s) + t.

Проверка: `test_u2_reference.py::test_vs_exact`, `test_u3_invariants.py`, `test_u5_u6_invariance.py`.
