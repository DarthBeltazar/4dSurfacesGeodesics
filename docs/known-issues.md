# Известные проблемы и ограничения

- **Туннелирование шага в плоских зонах.** Где кривизна ровно ноль, оценка ошибки ≡ 0 и шаг растёт ×5 за шаг;
  стадии RK могут перепрыгнуть тонкий слой кривизны, и ошибка перестаёт зависеть от tol. Лечится только
  ограничением шага (`Shape.hcap`: расстояние до носителя кривизны + доля масштаба внутри). Любая новая сцена
  с плоскими зонами обязана задавать hcap. (Найдено на компактной червоточине, см. журнал 2026-10-23-01.)
- **Неустойчивые орбиты.** Лучи у L ≈ b (фотонная сфера на горловине Эллиса) экспоненциально чувствительны
  к начальным данным; это физика. Ставится потолок попыток шага `n_max`, такие пиксели красятся отдельным цветом
  (пурпурный) и учитываются в `frac_step_cap`. Тест отклонения исключает L ∈ (0.9, 1.1)·b. Они же дают
  максимальную ошибку направления в рендер-бенчмарке компактной червоточины (L ≈ 0.999·b, ADR-0002).
- **Большие α нестабильны.** α = 10/ℓ_s на компактной червоточине при tol = 1e-4 даёт NaN (ADR-0001).
- **JAX на Windows — только CPU.** Метрика сравнения методов — проходы SDF на луч, а не миллисекунды.
- **Гладкая склейка M11 обрезана при q ≤ 1e-2** (хвост ≤ e⁻⁹⁹·W² отброшен); на нулевое множество и
  производные влияния нет на уровне float64.
