# v0.2.0-alpha — самостоятельный редактор нод для Windows

Рендерер искривлённых трёхмерных пространств: червоточины, S³ и торы. Свет идёт по геодезическим,
изображение строится трассировкой путей на GPU.

В этой версии приложение запускается без Python: распакуйте ZIP и откройте `run_editor.cmd`
или `geo4d_gpu.exe`. Установка пакетов, Vulkan SDK и интернет для запуска не нужны.

## Что нового после v0.1.0-alpha

- Редактор нод: холст, инспектор, проверка связей, undo/redo; открытие и сохранение сцен `.g4d`.
- Структурные правки сразу видны в предпросмотре, быстрые шейдеры собираются в фоне.
- Формулы геометрии, гладкая CSG объектов и преобразования; параметры объектов меняются без перекомпиляции.
- CSG многообразий: объединение, пересечение и вычитание; пример — `scenes/bubble.g4d`.
- Общие поля для двух ролей — многообразия и объекта. S³ и торы каталога доступны в обеих ролях.
- Прежние JSON-сцены открываются с переводом в граф. Сохранение — в `.g4d`.
- Переносимый архив с exe, DLL, шейдерами, библиотекой нод и сценами; кэш хранится
  в `%LOCALAPPDATA%\geo4d\cache`. Рядом с ZIP опубликована контрольная сумма SHA-256.

## Скачать и запустить

1. Скачайте `geo4d-editor-0.2.0-alpha-win64.zip` и распакуйте целиком.
2. Запустите `run_editor.cmd` или `geo4d_gpu.exe`.
3. При первом запуске приложение скомпилирует шейдеры.

```bat
run_editor.cmd
run_editor.cmd scenes\S3.json --fullscreen
run_editor.cmd scenes\bubble.g4d --res 1920x1080
```

Аргумент сцены теперь передаётся путём. Для запуска нужны Windows x64, GPU с Vulkan 1.3 и свежий драйвер.
Денойзер OptiX доступен на NVIDIA; при его недоступности приложение работает без денойзера.

## Управление

- W/S, A/D, Q/E — полёт, Shift — быстрее; C/Z — крен.
- ЛКМ по кадру и мышь, стрелки — взгляд; средняя кнопка по объекту — выбрать его ноду.
- F1 — панели, F11 — полноэкранный режим, R — денойзер, P — предпросмотр.
- Esc — отпустить мышь / выход.
- ПКМ по холсту — добавить ноду; Delete — удалить; Ctrl+Z / Ctrl+Y — отменить / повторить.

## Ограничения альфы

- Проверено на Windows с RTX 4080 SUPER. AMD и Intel не проверены; готовых сборок Linux/macOS нет.
- Текстуры и PBR-материал ещё не реализованы. Объект-формула требует корректной границы Lipschitz от автора сцены.
- Изредка возможна пурпурная точка в фоне (известная проблема режима A).
- Ручная проверка всех действий мышью по холсту не выполнена; автоматические проверки используют директивы редактора.
