## Подготовка
- Проверены история после первого тега, состояние рабочей копии и релизы GitHub.
- В релиз входят DD-010, шаги 1–6 DD-011, DD-014 и DD-015.

  exe, Slang/SDL/CRT DLL, shaders, nodes, scenes. Компиляция всех JSON/G4D-сцен проверяется
  упакованным exe; временные графы и кэш не попадают в архив.
- README архива содержит управление и ссылку на точный коммит исходников, build.json — версию;
  рядом с ZIP — SHA-256. Изменённые отслеживаемые файлы блокируют упаковку.
- Обновлены CHANGELOG, быстрый старт README и версия Python-проекта.
- В архив включён каталог `licenses/`: уведомления компонентов из используемых исходников и тегов.
- `gpu/build.cmd` выполнен в Release. Запущены GPU- и CPU-регрессии.

## Что не получилось и почему
- Сборка и GitHub CLI из песочницы не имели доступа к MSVC/конфигурации gh:
  повторены через разрешённый запуск с повышенными правами.
- GitHub compare по локальному HEAD вернул 404: новые коммиты ещё не отправлены.
  Локальная проверка истории подтверждает, что HEAD содержит удалённый master;
  публикация — обычным fast-forward push.
- Неотслеживаемые AGENTS.md и tests/test_lens.py оставлены на месте и не включаются в коммит.
  У линзы отсутствует реализация mf.lens; её экспериментальный тест исключён из регрессии релиза.
- Первый вызов cmd-лаунчера в проверочном скрипте имел неверное экранирование кавычек Windows.
  Исправлен вызов subprocess: для cmd /s /c передаётся готовая командная строка; обе сцены затем прошли проверку.
- pytest не смог записать свой служебный кэш в песочнице; тесты завершились успешно.
