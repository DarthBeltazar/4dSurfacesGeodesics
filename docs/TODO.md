## 1. CSG над многообразиями ([DD-014](design/DD-014-manifold-csg.md): шаг A сделан — ноды, метаданные, ℓ_s; шаг B — свой радиус шаров)
Ноды многообразий «объединение / пересечение / вычитание» со сглаживанием **с компактным носителем**:
min(a, b) = (a + b)/2 − s(a − b)/2, s ∈ C∞, s(t) = |t| при |t| ≥ k. Вне полосы |f₁ − f₂| < k f совпадает с одним из
кусков ⇒ плоские зоны остаются точно плоскими, метаданные (листы, шары носителей, `hcap`, выход) выводятся.
Примеры: гиперплоскость ∪ сдвинутая S³ → червоточина в сферический мир («мешок с золотом» Уилера); слой |w| < W
минус 4-шар → обычная червоточина между листами (горловины M35 — частный случай).
Риски: ∇f = 0 на M при некоторых k (пережатие шейки) — проверка при загрузке; знак f (сторона «внутри») —
переключатель у входа. Экспоненциальный smin (M6) не годится: нет точно плоских зон (`hcap`, NEE, выход на фон).

## 2. Одна нода «поле 4D» для двух ролей
Шар, гиперплоскость/полупространство, формула — одна нода; роль задаёт выход, к которому подключена
(`scene.manifold` или `out.object`), проверки — по роли: для многообразия гладкость и метаданные (M37), для объекта —
граница расстояния, константа L (M36). Неподходящие для роли ноды не подключаются (с пояснением): `mf.ellis`,
`mf.throat` как объект, `obj.union` (экспоненциальный smin) как многообразие. Преобразования `xf.*` — в обоих
контекстах (как они меняют метаданные многообразия — уже в M37). Меню: общая группа «Поля».

## 3. Один PBR-материал (metallic–roughness)
Параметры: `base_color`, `metallic`, `roughness` (α = roughness²), `specular` (F₀ = 0.08·specular), `emission` +
`strength`. BSDF — смесь Ламберт + GGX с Френелем (Schlick), согласованный pdf для MIS; эталон в `pathtrace.py`,
тесты: печь (≤ 1), NEE+MIS = только BSDF, GPU против прототипа; альбедо для AOV денойзера. Миграция: `mat.diffuse` →
metallic 0, specular 0 (кадры старых сцен должны совпасть), `mat.metal` → metallic 1, `mat.emit` → emission.
Не в этой версии: стекло/преломление, anisotropy, clearcoat.

## 4. «Значение / текстура» у параметров материала
Кнопка у параметра в инспекторе: ползунок заменяется входным портом, подключённая текстура заменяет константу.
`.g4d` хранит список включённых входов; включение — структурная правка (предпросмотр сразу, быстрый граф в фоне).
Зависит от шага 7 DD-011 (контекст текстур, `tex.*`, вычисление в точке попадания, альбедо в AOV).
