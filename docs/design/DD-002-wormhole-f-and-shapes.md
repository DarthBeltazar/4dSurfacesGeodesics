# DD-002: Неявная f для червоточины с компактной кривизной и библиотека фигур
Статус: Accepted (принят самостоятельно)
Этап: 1        Дата: 2026-10-23

## Контекст и задача
Нужна червоточина, у которой вне ограничивающей сферы оба листа — ровно плоские гиперплоскости, чтобы
лучи снаружи летели по прямой аналитически. Профиль r(ℓ): чётный, C² или гладче, r(0) = b, r′(ℓ) = sign(ℓ)
при |ℓ| > ℓ₀. Плюс библиотека тестовых фигур из TASK.md.

## Цели / не-цели
- Цели: f гладкая (C∞) в окрестности M, ∇f ≠ 0 на M, без жёстких min/max/abs в геометрии,
  дешёвая (несколько трансцендентных функций), аналитическая (без таблиц) — проще для GPU и для jet-чисел.
- Не-цели: точная SDF (важно только нулевое множество).

## Математика
M11 (одна червоточина), M12 (две), M9 (эталонная квадратура), M6 (гладкие примитивы).

## Предлагаемое решение

### Червоточина с компактной кривизной
f = w² − h(ρ), h(ρ) = W² ψ((ρ − b)/(ρ₀ − b)), ψ(u) = 1 − exp(1 − 1/(1 − u)) при u < 1, иначе 1.

Почему именно так:
- Форма «w² − h(ρ)» сразу даёт чётность по w (оба листа симметричны) и r = ρ (площадной радиус
  совпадает с ρ), так что профиль r(ℓ) читается напрямую из h.
- Горловина там, где h = 0, т.е. ρ = b; h′(b) ≠ 0 ⇒ ∇f ≠ 0 и поверхность гладкая, хотя w = √h имеет
  корневую особенность как функция ρ (это особенность графика, а не поверхности).
- ψ — склейка типа exp(−1/x): все производные h обнуляются в ρ₀, при ρ ≥ ρ₀ h ≡ W², листы w = ±W.
  Кривизна строго равна нулю вне шара, а не «мала».
- При ρ < b h < 0 ⇒ f > 0: других компонент нулевого множества нет.
- Выбор ветви u < 1 / u ≥ 1 делается по значению, обе ветви — одна и та же C∞ функция
  (как в M6); это не «жёсткий max» в смысле задания: f бесконечно гладкая.

Параметры по умолчанию: b = 1, ρ₀ = 3, W = 1.5 (подбираются так, чтобы кривизна была заметной,
но без экстремально острых складок; проверяется картинкой и числом шагов).

### Две червоточины
M12: f = w² − (h(ρ₁) + h(ρ₂) − W²) при непересекающихся шарах. Объекты — этап 4.

### Библиотека фигур
Гиперплоскость, S³, S²×R, S¹×R², трёхосный эллипсоид, сферитор, ториосфера, «тигр», Эллис, компактная
червоточина. Каждая фигура задаёт: f (на `ops`), масштаб ℓ_s, список плоскостей сохраняемых моментов,
сэмплер точек на M (параметризация + уточнение Ньютоном), опционально точное решение и функцию выхода.

## Рассмотренные альтернативы и почему отвергнуты
- **Параметризация r(ℓ) + 1D-таблица для неявной f** (например, f = ρ − R(w) с табличной R):
  таблица усложняет GPU и jet-производные (нужна гладкая интерполяция до гессиана), а аналитический
  вариант нашёлся.
- **f = ρ − R(w)** с аналитической R: горловина требует R′(0) = 0, а уход в плоскость — R(w) → ∞ при
  w → ±W, т.е. особенность; плоские листы как график ρ(w) не выражаются.
- **Полиномиальная склейка C²**: в правой части M2 стоит гессиан ⇒ C² f даёт лишь непрерывную правую
  часть, и наблюдаемый порядок падает на стыке. C∞ склейка этого не делает.

## Бюджет производительности и памяти
Одна exp, одна length, несколько умножений — дешевле Эллиса (cosh).

## План проверки
U1–U6 на компактной червоточине; угол отклонения против квадратуры M11; численная проверка r′(ℓ) = 1
при |ℓ| > ℓ₀ и гладкости профиля (тест).

## Риски и открытые вопросы
- exp(1 − 1/(1 − u)) имеет большие высшие производные около u → 1: адаптивный шаг будет там дробиться.
  Если это заметно в бенчмарке — вариант с более мягкой склейкой (ψ через стандартный smooth step
  exp(−1/x)/(exp(−1/x) + exp(−1/(1−x)))).
