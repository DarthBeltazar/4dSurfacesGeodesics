# DD-001: Интегратор геодезических
Статус: Accepted (принят самостоятельно, см. docs/log/2026-10-23-01.md)
Этап: 1        Дата: 2026-10-23

## Контекст и задача
Нужен интегратор лучей-геодезических на неявной гиперповерхности f = 0 в R⁴: jet-числа вместо
конечных разностей, BS32 с FSAL и адаптивным шагом, стабилизация Баумгарта и проекция.
Прототип на Python + JAX (float64, CPU) — эталон для GPU-порта на этапе 3.

## Цели / не-цели
- Цели: корректность (U1–U6), точность, привязанная к угловому размеру пикселя; счётчик вызовов SDF
  на луч для честного бенчмарка; один и тот же код SDF для jnp-массивов, Jet7 и Jet15.
- Не-цели: скорость на CPU (метрика сравнения — вызовы SDF, а не миллисекунды), поля Якоби (DD-003).

## Математика
M2 (правая часть), M3 (проекция), M4/M5 (jet-алгебра), M6 (гладкие примитивы), M7 (BS32), M8 (норма ошибки).

## Предлагаемое решение

### Числовой слой (`prototype/geo4d/jet.py`)
- `Jet7(a, b, c, d)` и `Jet15(a, g, H)` — зарегистрированные pytree JAX, поля — массивы.
  Перегружены + − * / ** (целая степень), сравнение не перегружается.
- Пространство имён `ops` (sqrt, exp, cosh, sinh, log, smin, length, where): диспетчеризация по типу.
  SDF пишутся один раз как функции `f(p)` от кортежа из 4 компонент и работают на jnp-скалярах
  (эталон через `jax.jacfwd`/`jax.hessian`), Jet7 и Jet15.
- `jax_enable_x64` включается в `geo4d/__init__.py` до создания любых массивов.

### Правая часть (`rhs.py`)
Один проход SDF на Jet7 с засевом (x_k, v_k, 0, e_k) даёт f, ∇f, ∇f·v, vᵀHv — всё, что нужно для M2,
и одновременно f, ∇f для проекции M3. Правая часть возвращает и производную состояния, и сами jet-данные.

### Интеграторы (`integrators.py`)
- Общий вложенный RK с FSAL по таблице Бутчера: BS32 (рабочий) и DOPRI5 (сравнение).
- Фиксированный шаг: RK4 и наивная схема «x ← x + h v, проекция, перенос v».
- Цикл — `lax.while_loop` на один луч, батч — `vmap`.
- Состояние цикла: x, v, h, s (длина пути), k1 (FSAL), счётчики шагов / отказов / вызовов SDF, флаг завершения.
- Завершение: функция выхода сцены (escape) | s ≥ s_max | число шагов ≥ n_max (помечается отдельно).
- Шаг ограничивается: h ≤ h_max, h ≤ s_max − s, h ≤ g(x) (SDF объектов; на этапе 1 — заглушка ∞).

### FSAL и проекция
k4 считается в непроецированной точке y⁺. Он же даёт f и ∇f для проекции (M3) — дополнительного вызова SDF нет.
Дальше k1 следующего шага можно получить двумя способами:
- **stale**: взять k4 как есть, заменив только компоненту ẋ = v на спроецированную v. Ускорение
  устарело на O(f) + O(|δv|). 3 вызова SDF на шаг.
- **reeval**: заново вычислить jet в спроецированной точке и при необходимости повторно спроецировать v
  по точной нормали. 4 вызова SDF на шаг.

Выбор по умолчанию делается по измерению (бенчмарк, этап 1): что дешевле при равной угловой точности.

### Норма ошибки и допуск
M8: максимум касательной ошибки позиции (в единицах ℓ_s) и касательной ошибки направления.
Допуск первичного луча tol = κ · θ_pix (θ_pix — угловой размер пикселя, κ ≈ 0.1; уточнить в ADR после измерений).

### Параметр α
Порядка 1/ℓ_s (ℓ_s — масштаб геометрии). С проекцией после каждого шага Баумгарт действует только внутри шага;
влияние α измеряется, итоговое значение фиксируется в ADR.

## Рассмотренные альтернативы и почему отвергнуты
- Конечные разности для ∇f и H — запрещены заданием, теряют точность.
- `jax.jvp`/`jax.hessian` в рабочем пути — допустимы для эталона, но не переносятся на GPU-шейдер;
  jet-типы — то, что будет на этапе 3.
- Внутренняя форма (координаты на M + символы Кристоффеля) — нет глобальных карт для торов и S³.

## Бюджет производительности и памяти
На шаг BS32: 3 прохода Jet7 (stale) или 4 (reeval). Проход Jet7 ≈ 7× стоимости скалярного SDF.
Цифры шагов на луч — по результатам бенчмарка (results/stage-1/…).

## План проверки
U1 (jet), U2 (DOP853 и точные решения), U3 (инварианты), U4 (обратимость), U5, U6,
сходимость (порядок ≈ 3 при фиксированном шаге), бенчмарк вызовов SDF. Подробно — DD-006.

## Риски и открытые вопросы
- stale-FSAL может снижать эффективный порядок — измерить.
- Лучи у неустойчивых орбит (горловина Эллиса, L ≈ b): потолок шагов, пометка.
